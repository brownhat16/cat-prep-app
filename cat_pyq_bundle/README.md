# CAT Previous Year Question Papers Bundle

This bundle contains a curated index of publicly accessible CAT previous-year question paper sources.

It does not mirror or redistribute the PDFs themselves. Instead, it packages:

- `cat_previous_year_papers_links.csv`: slot-wise / year-wise links
- `sources.md`: source notes and availability caveats

Notes:

- Bodhee Prep states that official CAT papers were released from 2017 onward, and that 2009-2016 papers are unofficial or memory-based.
- AglaSem maintains a CAT previous-year papers hub covering 2009, 2010, 2011, 2012, 2017, 2018, 2019, 2020, 2021, 2022, and 2023.
- For 1991-2008, the bundle uses Bodhee Prep links where they were publicly listed.
- A few entries point to landing pages instead of a direct PDF when the slot PDF link was not reliably exposed.

Open the CSV in Excel / Numbers / Google Sheets, or use it as a download checklist.
